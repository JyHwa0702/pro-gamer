## 리뷰 경계

버튼 크기를 키워 닫기/사진/금액이 가려지면 안 된다. 중복 설명을 숨겨도 가격/효과·계약/관계 선택이 사라지면 안 된다. 표시 함수 호출 순서가 새 난수/선수 변경을 만들면 안 된다. 자동·1주 진행 버튼은 원래 콜백으로 연결한다. 구세이브의 미확정/없는 옛 세트는 생성하지 않는다.

검증은 합성 저장소·별도 Chromium 컨텍스트를 사용한다. 실제 휴대폰/OS 키보드/설치PWA/사람의 재미 검증과 구분한다. 기존 미커밋·Riot문의·사용자 Android 빌더/패키지를 보존하고 배포/push/재빌드는 하지 않는다.
