# Road to Worlds 장기 게임 기획

기준: 2026-11-03. 사용자 결정: 경기·구단 전략과 23인 인연 서사를 균형 있게 발전시킨다. 1차는 시즌 전체를 관통하는 묶음으로 구현한다.

## 2026-11-05 현재 우선순위

사용자가 기능 확산보다 굵직한 목적·간단한 UI·자동 진행을 요청했다. 이후 우선순위는 **선수 커리어와 책임 있는 관계 두 축**이다. 개막의 동행 파티 선택은 제거하고 과거 기록만 보존한다. 공식 연인1명+썸2명, 사진/멘트 선택형 인스타를 사용한다. 기존 아래 단계는 기획 이력이며 FA/5인 로스터는 다음 즉시 구현 대상에서 뒤로 미룬다.

다음 큰 묶음은 ‘실제 BO3/BO5 한 시리즈→주전 평가→계약→결산’, 이어서 ‘대표3인의 관계 선택이 다음 시즌까지 이어지는 후일담’이다. 자동으로 시즌 전체를 달리는 기본 흐름 안에서 직접 결정할 핵심만 남긴다. 자세한 현행 범위와 다음 단계는 `reports/CORE_GAME_AUDIT_AND_RESET_2026-11-04.md`를 따른다.

## 게임의 약속

나만의 선수로 전설에 도전하고, 함께한 사람들과 은퇴 이후까지 이어가는 e스포츠 인생 시뮬레이션.

성장 수치만 올리는 반복을 넘어 목표→준비→경기→사람들의 반응→다음 선택→시즌 결산이 이어진다. 돈은 준비와 생활·관계에 쓰이고, 인기는 기회를 연다. 인기 자체를 소모하는 토큰으로 바꾸지 않는다. 부자·유명 선수도 경기력과 컨디션 없이 승리를 살 수 없다.

## 커리어 전체

| 구간 | 전략 | 관계와 이야기 | 돈·인기의 의미 |
|---|---|---|---|
| 무명·연습생 | 훈련·랭크·스카우트 | 먼저 믿어준 사람, 동기와 경쟁 | 제한된 예산, 작은 협업 기회 |
| 데뷔·주전 | 실전과 팀 호흡 | 첫 승·부진·콜업에 대한 서로 다른 반응 | 급여·준비 비용, 팬과의 약속 |
| 우승 도전 | 대진·폼·시즌 운영 | 라이벌, 함께 버틴 사람, 선택 기억 | 후원·행사·생활 안정의 기회비용 |
| 전성기 | 잔류·이적·국제대회 | 성공 뒤 책임, 각 인물 자신의 목표 | 계약·브랜드·다음 세대 투자 |
| 은퇴·계승 | 유산과 구단 운영 | 커리어별 결말, 인연별 후일담 | 자본·인맥을 활용한 육성 |

연차로 성공을 강제하지 않는다. 늦은 데뷔·우승 없는 커리어·여러 팀 이적도 결산과 후일담을 가진다.

## 세 번의 큰 업데이트

### 1차: 한 시즌이 이야기되는 게임

시즌 목표, 실제 일정·순위·다음 상대, 기존 경기를 관찰하는 라이벌 기록, 주요 분기 평가, 인연 동행 선택·후일담, 돈/인기 활용, 26주 결산과 기록 재열람을 함께 제공한다. 기존 브리핑이 매주 결과를 설명하고 시즌 카드가 장기 목적을 보여준다.

대표 인연은 지은(생활과 응원), 하린(경기와 라이벌), 민아(팀과 커리어)부터 고유 대사를 연결한다. 다른 해금 인물도 동행자로 선택할 수 있고 안전한 공통 시즌 반응을 제공한다. 기존23인 콘텐츠는 보존한다.

### 2차: 선택에 따라 달라지는 커리어

플레이 스타일·주전 경쟁·감독 신뢰·잔류/이적의 장기 약속을 연결한다. 23인은 자기 목표, 커리어 접점, 기억하는 선택, 후일담을 각각 갖는다. 이미 저장한 선택을 실제 후속 대사에 반영한다. 경기력·팀 기여·관계의 서로 다른 경력 결말을 설계한다. 재계약 기본 확률/급여를 바꾸기 전에 장기 분포를 검증한다.

### 3차: 은퇴 이후의 계승

현재 유망주 후원·코칭 회차에서 실제5인 로스터 운영으로 확장한다. FA 후보 비교, 급여·출전 기회·잠재력, 코치·팀 색깔·구단 재정이 함께 돌아가게 한다. 기존 커리어를 소급 초기화하지 않고 명시적 전환으로 계승한다. 선수 시절 자본·성과·인맥은 서로 다른 선택지를 제공한다.

## 1차 세부 명세

### 26주 흐름

- 첫 진입: 도전/기본기/균형 목표와 해금 인연 동행자 선택. 기존 진행 중 세이브는 현재 주부터 합류한다.
- 1~8주 스프링: 목표 준비·리그 순위·다음 상대·실제 라이벌 경기 기록.
- 9주: 스프링 평가. 성적과 목표 진행에 대한 감독/동행 인연 반응, 솔직한 회고/다음 계획 선택.
- 12주: 서머 준비. 라이벌 분석/자기 페이스 선택과 후속 대사 연결.
- 20주: 서머 결산. 승패에 맞춘 격려·책임 대화.
- 23주: 월즈 결과/관전의 서로 다른 평가. 다음 시즌 약속 선택.
- 24주: 기존 계약 결과를 시즌 일지와 결산에 포함.
- 26주: 목표·성장·경기·라이벌·지출·선택 기억·동행자의 후일담을 한 번 결산한다. 우승하지 못해도 결말을 준다.

중요 선택은 시즌당 최대6회(개막 포함)로 제한한다. 매주 새 모달을 추가하지 않는다. 이야기 선택은 후일담을 바꾸며 무료 능력치·급여·우승 보상을 중복 지급하지 않는다.

### 목표와 장기 보상

- 도전: 아마추어는 기준 랭크보다 한 단계 높은 티어 또는 입단, 팀 선수는 남은 기간에 비례한 공식전 승수.
- 기본기: 포지션별 훈련 일정의 지속성. 추천은 기존 능력치·컨디션을 사용한다.
- 균형: 훈련과 서로 다른 주의 인연 소통을 함께 기록한다.
- 달성은 시즌 기록·서사적 평가로 남긴다. `hist.titles`에 가짜 우승을 추가하거나 기존 업적 보상을 발동하지 않는다.
- 시즌 중간 합류는 남은 기간에 맞춰 목표를 줄이고 과거 실패를 소급 판정하지 않는다.

### 돈·인기 활용

기존 주식·임대·주거·차량·기어·팬클럽·선물은 유지하고 시즌 화면에서 역할을 안내한다. 새 선택은 각 종류 시즌1회, 팬은 감소하지 않으며 모두 명시적 실행이 필요하다.

| 선택 | 조건/대가 | 효과와 제한 |
|---|---|---|
| 훈련 환경 지원 | 단계별 최소3만/25만/100만원 또는 보유 현금1% 중 큰 금액 | 체력+6, 스트레스-6, 팀 소속이면 시너지 최대+0.3. 스탯·경기 확률 직접 가산 없음 |
| 팬 초청 공개행사 | 팬1000·OVR40 이상, 최소10만원 또는 현금0.5%, 체력8 | 팬 증가 최대300, 스트레스-4. 팬·실력에 따른 행사 선택권 |
| 인터뷰 협업 | 팬500·OVR40 이상, 체력6·스트레스+6 | 출연료 최대50만원, 팬 수의 제곱근과 OVR로 산정. 반복 수익 불가 |
| 동행 기록집 | 해금 동행자, 최소5만원 또는 현금0.2% | 동행 호감도+2(100상한), 기록집 전용 후일담. 추가 데이트가 아님 |

현금이 많아도 일정당 효과는 동일하다. 비용/효과/횟수/현재 충족 조건을 실행 전에 표시하고 취소는 무소모다. 인기만 높고 OVR이 낮으면 협업·행사 조건을 통과하지 못한다. 실행 시 저장하고 재로드·연타·동일 주/다른 주 반복을 막는다.

### 저장과 화면

선택 상태 `seasonJourney`, 최근12시즌 `seasonArchive` 추가. 구버전 누락/손상은 기본값으로 보완하고 실제 선수·자산·기존 기록은 보존한다. 인연의 과거 선택은 추정해서 만들지 않는다. 이야기 재열람은 선택/보상을 재실행하지 않는다. 진행 중 새로고침은 그 주의 시작 전 체크포인트로 복구하고, 완전히 마친 주만 확정 저장한다. 다음 시즌 개막에서 지난 동행과 마지막 약속을 다시 읽는다.

홈 시즌 카드→시즌 허브(목표·실제 일정·다음 상대·라이벌)→준비/활동→일지·과거 결산으로 이어진다. 숫자·SVG·짧은 대사·초상화를 사용하고 상세 내역은 펼친다. 기존 하단6개 메뉴는 유지한다.

## 지속 검증 기준

- 기본 일정만 진행한 대조군은 신규 기록 외에 상태·정산·주가·난수가 이전 버전과 일치해야 한다.
- 각 신규 활동의 비용/수익/체력/스트레스/호감도 상한과 중복 실행을 별도로 검증한다.
- 역할·출발 단계·연차·성장 정책을 바꾼 여러26주/78주 실험으로 무료/유료 경로를 비교한다.
- 실패·부진·해고·중간 합류·자연 은퇴·새 커리어에서 이야기/일지/결산이 연결되어야 한다.
- 미성년 참여자는 공개 응원·청춘 서사만 사용한다. 새 활동에 성인 의상/접촉 연출을 넣지 않는다.
- 실제 클릭→한 시즌→결산→재로드·재열람, 모바일/PC·오프라인을 검사한다. 정적 파이프라인 PASS와 실제 플레이 검증을 구분한다.

## 범위와 전달 원칙

이번1차는 새로운 감독 신뢰 게이지·실제 FA/5인 로스터·새 경기 확률·급여 공식까지 동시에 도입하지 않는다. 이후 업데이트와 연결할 시즌 기억·지출·동행 기록을 마련한다. 단일 파일/PWA 구조·기존 세이브 키를 유지하고 버전은4곳 동기화한다. 커밋·배포·APK 재빌드는 별도 요청 시 진행한다.

사용자 보고는 짧은 핵심, 변경된 플레이 표, 검증 결과 표, 미검증 범위와 문서 링크 순으로 제공한다. 긴 설계 설명은 문서에 둔다.

# 2026-11-04 진행 반영: 한 시즌 재미 보완

로컬v2.7.0에서 계약/엔딩 사실 판정, 실제 목표 추천, 대표3인의 청춘 준비·후속 선택, 일반 결과 홈 정리, 밝은 공통 화면을 구현했다. 상세는 `docs/reports/SEASON_POLISH_RESULTS_2026-11-04.md` 참조. 3차 FA 확장은 다음 우선순위로 바로 뛰어넘지 않고 실제 첫 시즌 피드백과 경기 준비/숙련도·유료 분석의 실질 결과를 확인한 뒤 진행한다. 기존 장기 방향과 보유 자산을 유지한다.
