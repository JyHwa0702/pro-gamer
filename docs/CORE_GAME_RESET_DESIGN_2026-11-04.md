# 핵심 경험 재정렬 · v2.8.0 / 21

## 목적

**한 번 눌러 시즌을 달리고, 중요한 경기와 사생활의 선택만 직접 하는 e스포츠 커리어 게임.** 관리 항목을 늘리는 개발을 멈추고 선수 생활·책임 있는 관계 두 축으로 묶는다. 사용자는 연인1명+썸2명(총3명)을 확정했다.

## 통합 범위

1. 홈은 이번 무대·대표 능력·자동 진행을 중심으로 간소화한다. 기존 재산/장비/프로젝트는 더보기와 상세에 보존한다. 히로인을 선수의 파티원처럼 지정하는 ‘시즌 동행’ 선택과 표현을 제거한다. 과거 아카이브는 보존한다.
2. 완전자동은26주까지 입력 없이 훈련·회복·밴픽·경기·일반 대화를 진행한다. 성장/승급/균형 전략과 ‘중요 선택은 직접’ 모드를 선택할 수 있다. 중지/새로고침의 주간 저장 경계는 기존 규칙을 사용한다.
3. 수동과 자동 경기는 같은 국면/상성/조합/숙련/QTE 판정을 사용한다. 챔피언45명·포지션별9명, 대회는10밴/10픽 중복금지, 블라인드는 양팀 미러 허용. 실제 세트별 피어리스는 별도 시리즈 엔진이 없어 구현했다고 주장하지 않는다.
4. 친분 수치는 보존하고 연애 상태를 별도로 관리한다. 공식연인1명·썸2명, 낮은 친분 고백 거절·4주 거리두기, 실제 비밀 데이트/공개 게시물 증거로 질투·신뢰 하락·반복 시 이별. 질투를 무료 호감 보상으로 만들지 않는다.
5. 인스타는 실제로 함께 남긴 사진 → 준비된 멘트 → 게시로 단순화한다. 기존 직접 입력 코드는 보존하지만 기본 화면은 선택형으로 통일한다. 사진 속 실제 상대를 저장해 태그만 바꾸는 우회를 막는다. 게시/DM 보상은 기존 주간 상한을 유지한다.
6. 지은·하린·민아 공개 장소 기념컷과 공용 뒷모습컷을 사용한다. 모두 두 사람이 한 장면에 나오며 비접촉·건전한 복장이다. 대화의 장소/기분에 따라 안전한 원본 장면·감정 표시·만남 기념컷을 선택한다. 모든 미성년 보호는 유지한다.

## 검증 기준

- 수정 전 4인 무료DM 고호감, 질투 무료보상, 수동/자동 격차·중복픽·죽은숙련/QTE를 실제 재현한다.
- 동급전 자동 승률은 각 역할45~60% 범위를 목표로 하며 능력55<65<75의 효과를 확인한다. 공식 규칙과 게임용 추정 수치를 구분한다.
- 자동26주는 추가 입력0, 중지/연타/플레이어교체/취소/저장 경계를 확인한다.
- 연인1/썸2·거절/냉각·친구DM 우회·게시 증거/비밀 만남·중복 벌점/반복 이별을 검사한다.
- 실제 커플컷/멘트로 최소 조작 게시, 취소 시 무변경, 주간 보상1회, 오래된 피드/세이브 보존을 검사한다.
- StageShow는 별도 시각 데모로 제작해 실제 기능 증거와 구분한다. 단순한 위계·짧은 원인 있는 모션은 실제 Vanilla UI에 적용한다.
- 필수pipeline/별도AST/버전4곳/전체회귀/Chromium반응형과오프라인 확인 후 보고한다. 자동 배포·스토어 업로드는 이번 구현 결과와 구분한다.
