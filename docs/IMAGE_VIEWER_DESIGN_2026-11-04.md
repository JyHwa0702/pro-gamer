# 이미지 확대 뷰어 · v2.7.1 / 20

사용자 요청: 인물·장면 이미지를 눌러 확대해 볼 수 있어야 한다.

- 단일 index.html에 별도 native dialog 뷰어를 추가한다. 기존 게임 ask 모달이나 선택 Promise를 바꾸지 않는다.
- 장면 초상화·시즌 이미지·시네마틱·엔딩·피드·기록집·홈 챔피언 이미지는 전체 비율로 감상한다. 이미지가 메뉴/선택을 수행하는 챔피언 픽·필터·작은 탐색 아이콘은 기존 기능을 유지한다.
- 인연 목록은 사진=확대, 별도 인연 보기=기존 메뉴로 분리한다. 미해금 인물은 기존 잠금 유지.
- 현재 실제 표시 중인 이미지(currentSrc)를 사용해 Fallback 결과와 연령 보호를 그대로 따른다. 원본 성인 CG나 미해금 에셋을 추측해 가져오지 않는다.
- 화면 맞춤·1~4배 확대/축소·초기화·드래그·휠·두 손가락 확대·닫기/Escape·키보드 포커스를 제공한다. 이미지 추가와 저장 상태 변경은 없다.
- 확대 중 배경 입력 차단, 닫을 때 원래 화면/포커스 복귀. 모바일 회전/가시 영역 변화에 다시 맞추며 모션 줄이기를 존중한다.
