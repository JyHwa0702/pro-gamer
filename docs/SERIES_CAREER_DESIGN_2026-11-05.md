# 실제 시리즈에서 계약과 결산까지 · v2.9.0 설계/구현 계획

사용자 승인 범위: 실제 BO3/BO5→주전 평가→계약→시즌 결산을 한 흐름으로 개발. 완전자동 기본, 기존 세이브와 밸런스 보존. 이 문서는 기존 다음 단계 제안을 구현 명세로 구체화한 개발자 선택을 기록한다. 이번 작업에 웹 배포/APK 재빌드는 포함하지 않는다.

## 핵심 결과

매 세트의 밴픽·국면·클러치 판정을 실제로 실행하고, BO3는2승/BO5는3승을 먼저 얻으면 종료한다. 승자를 미리 정하거나 단판 결과에 가상 스코어를 붙이지 않는다. 시리즈의 평균 평점과 실제 세트 결과를 이후 평가·계약·결산이 함께 사용한다. 기본은 모든 세트를 자동 처리하고, 원하는 경우 직접 밴픽/국면 선택으로 전환한다.

## 접근과 결정

- 기존 playMatch를 세트 수만큼 반복하는 안은 기록·보상·체력·성장을2~5배로 만들어 제외했다.
- 세트 계산과 시리즈 정산을 분리하는 안을 선택했다. 기존 `win/rating/mySetW/mySetL` 반환을 유지하고 실제 `sets`를 부가한다. `hist.games`, `P.ratings`, 라이벌/주간 경기 항목은 시리즈당1개를 유지한다.
- 완전 독립 세트를 원확률 그대로 반복하면 기존20%가BO5 약5.8%,80%는94.2%로 바뀐다. 사용자 밸런스 보존을 위해 최종 세트 확률에 대칭적인 길이 보정을 적용하고 실제 고정 조건 분포를 비교한다. 목표는 기존 기준 대비 승률 최대5%p 안팎, 동급45~60%이다. exact RNG/완전 동일 결과를 주장하지 않는다. 보정 상수는 측정 후 기록한다.
- 현45명/역할9명은 BO5 피어리스에 부족하다. 이번에는 세트별 일반 드래프트이며 세트 사이 재사용을 허용한다. 피어리스·현행LCK전체일정복제·새구단경영은 범위 밖이다.

## 인터페이스/상태

- `playSingleSet(opp,label,big,automatic,context)` → 실제 단판 `{win,rating,phaseWins,adv,kda,championId,draft,autoContinue,effects}`. 최종 경기/돈/팬/숙련 지급 없음. QTE가 그 세트에 미치는 임시 효과는 계산 후 원래 수치로 복원하고 결과에 기록한다. 전역 선수 객체를 교체하지 않는다.
- `playMatch(opp,label,big=false,isFastAuto=false,options={})` → 실제 시리즈. 호출부가 `options.bestOf`를 명시한다. 생략 시 일반BO3/큰결승BO5 호환 기본값. `options.control='manual'` 또는 저장된 직접 경기 설정만 수동이며 시즌 완전자동은 우선한다.
- `commitSeriesResult(summary)` → ID/완료 조건 확인 후1회 정산. 중복 호출은 보상 없이 기존 결과를 반환한다. 세트와 시리즈 수를 분리한다.
- `P.seriesHistory || []`: 최근120시리즈. 경기 당시 년/주/구단/상대/형식/세트승패·픽/평점/POG/정산요약. 과거 세이브의 가상 스코어로 실제 세트를 창작하지 않는다. 손상 항목만 제외, 기존 커리어/아카이브 전체 초기화 금지.
- `P.seriesSequence || 0`: ID 단조 증가. `P.seriesPreferences || {control:'auto'}`: 기본 자동. 기존 저장키/필드는 유지.
- `careerPerformance()`: 현재 평가기간 P.ratings 평균/최근3시리즈 평균, 실제 새 시리즈 수/세트 수/최근 결과를 한 번 계산한다. 기존 스프링/서머 평점 초기화와 계약/콜업 임계값·제안확률은 유지한다. 계약 화면은 잘못된 ‘전체 시즌 평균’ 대신 ‘평가기간 평균’을 표시한다.
- 계약 당시 성과와 기준을 복사한 스냅샷을 계약 기록에 남기며, 시즌 결산도 완료 당시 실제 시리즈 요약을 복사한다. 재열람 시 현재 선수/팀 수치로 다시 계산하지 않는다.

## 예산·호환성

- 체력−8/기본 team+.5, mental+.25/숙련 총100은 시리즈당1회. 실제 사용 챔피언에 총100을 배분한다.
- QTE 성장/실패 비용은 실제 세트 중 대표1개의 효과만 반영해 세트 수만큼 반복 지급하지 않는다. 대표 세트는 완료한 실제 세트 중 균등 추첨한다. 평점은 전체 세트 평균이며, 팬의0~3국면 판정에는 대표 세트 활약을 사용한다. POG는 실제고평점후보세트비율×1.1(상한1)로시리즈승리때최대1회선발한다. 후보기준8.3/국면2이상과연간한도는유지한다. 금액·임계값·연간 한도는 유지하고 분포 차이는 별도 측정한다.
- 주간 일정 시작 전 체크포인트→주간 완료 확정 저장을 유지한다. 세트 중간 영구 보상/부분 저장 없음. 선수 교체/오류에서는 다른 선수에게 효과를 적용하지 않는다.
- 과거 ratings/커리어/혼인/사진/시즌 결산을 보존한다. 새 형식 기록이 없는 과거 구간은 ‘세트 상세 없음’으로 표시한다.
- 23인 연령보호/연인1+썸2/데이트주1회/SNS주간상한/Vanilla단일HTML/PWA 유지. 새 이미지 없이 기존 UI/아이콘 사용.

## 연결 화면

홈 주간 결과는 최종 스코어와 평가를 짧게 표시하고 세트별 픽·승패·평점은 접힌 상세에서 본다. 기록 화면에서 최근 시리즈를 재열람한다. 시즌 커리어 패널은 최근3시리즈와 평가기간 평균을 나눠 설명한다. 계약 제안은 동일 성과 요약과 해당 구단 경쟁 기준을 보여준다. 시즌 결산에는 실제 시리즈/세트 승패와 계약 선택의 근거가 함께 남는다. 일반 자동 흐름에 추가 확인창을 만들지 않는다.

## 특별 리뷰 항목

1. 조기 종료 뒤 남은 가상 세트가 기록되거나 보상이 다시 지급되지 않는가.
2. 경기 중 콜업/계약으로 구단이 바뀌어도 실제 소속이 보존되는가.
3. 옛 기록과 새 세트 기록을 섞어 시즌 총계를 부풀리지 않는가.
4. ‘남은 경기 자동’ 선택이 다음 세트의 밴픽·QTE·해금에도 전파되는가.
5. 중간 새로고침/선수 교체/취소에서 주간 확정과1회 정산이 지켜지는가.
