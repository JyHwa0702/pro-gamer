# ② 미드나이트·시안 적용 계획

> 실행: writing-plans / executing-plans 기준으로 현재 작업 브랜치에서 구현하고 끝에 독립 리뷰를 수행한다. 이전 미커밋 작업을 보존한다.

**목표:** 사용자가 선택한 색상 시안②를 실제 게임의 공통 화면에 적용하고 기존 진행·세이브·밸런스를 유지한다.

**승인 근거:** 6가지 같은 UI 색상 비교 후 사용자 답변 ‘2번으로 가자’. 추가 색상 선택을 묻지 않는다. 배포 금지는 유지한다.

**아키텍처:** Vanilla 단일 index.html 안의 CSS 토큰과 화면별 색상만 정리한다. 레이아웃/선택 흐름/경기/관계/경제 함수를 바꾸지 않는다. 기존 사진·확대·연령 제한·애니메이션 및 모션 줄이기를 유지한다.

**색상 사양:** 배경 `#111a24`, 패널 `#1d2b3a`, 경계 `#354b60`, 본문 `#e9f0f4`, 보조글 `#a4b6c6`, 주요 선택 `#80c9d5`, 주요 버튼 글 `#12262c`. 승패/보상은 이 어두운 표면에서 읽히는 별도 의미 색을 유지한다.

## 리뷰 경계

사진 위 글은 실제 배경 사진과 함께 확인한다. 빨강/초록은 색만이 아니라 승리/패배·증가/감소 문구도 유지한다. 비활성 버튼과 보조글을 혼동하지 않도록 한다. 플랫폼 실제 OS 키보드·실제 기기 디스플레이·사람의 재미는 Chromium 모의 검사와 구분한다.

이번 범위에서 새 플레이 시스템·보상·히로인·세이브 필드·대회/챔피언 교체·앱 재빌드·배포·push는 하지 않는다. 전체 베타 완료 여부는 색상 적용과 별도로 기존 베타 계획의 남은 기준을 확인한다.
