# 첫 웹 베타 후보 — 범위와 완료 기준

상태: **로컬 웹 베타1 검토 후보 · v2.9.5/27 · 미배포.** 선택② 미드나이트·시안에 이어 사용자가 승인한 정보 배치·반복 문구·모바일 터치 영역까지 묶어 보강했다. 아래 정의한 로컬 자동검증 게이트를 충족했다. 실제 기기·사람의 첫 플레이와 공개 배포 승인은 별도다. 배포 금지 유지.

## 베타1에서 끝낼 범위

목표는 신규 시스템의 수가 아니라 **선수 생성→주간 육성→LoL 챔피언 경기→인연→계약→결산→다음 시즌**이 모바일 웹에서 이해되고 완주되는 경험이다. 로컬에서 검토 가능한 첫 웹 베타 후보까지 개발하며, 공개 배포·push·Android 재빌드는 하지 않는다.

1. **게임 화면 정체성:** 선택한 시각 방향을 홈·경기·결산·인연·SNS·상점에 적용. 과도한 둥근 카드·밝은 보라 그라데이션·아이콘 남발을 줄이고, 팀/챔피언·라인업·스코어·능력치와 명확한 주요 행동을 중심으로 정리한다. 색만 덮는 변경으로 완료하지 않는다.
2. **긴 선택 메뉴:** 실제로 긴 상점·자산/생활·인연 선택을 점검하고, 같은 정보의 반복과 한 번에 길게 나열되는 항목을 줄인다. 비용·효과·보유/사용 상태는 읽을 수 있어야 하며 원래 선택 인덱스·구매/판매 수량·취소·금액은 유지한다. 표시용 분류/필터가 게임 상태를 바꾸면 안 된다.
3. **모바일 조작:** 320/390px·짧은 세로 화면·가로 화면에서 본문·닫기·하단 메뉴·키보드를 점검한다. 중요한 터치 대상44px, 글/금액/사진 잘림 방지, 스크롤 후 닫기·뒤로 돌아오기·이미지 확대 유지.
4. **첫 시즌 전달:** 새 이용자가 실제 랭크·성장·입단 목표와 다음 할 일을 파악할 수 있어야 한다. 프로 합성 시나리오와 신인 시나리오를 구분해 검사하며, 첫 시즌 승격이나 월즈 우승을 보장하려고 밸런스를 바꾸지 않는다.
