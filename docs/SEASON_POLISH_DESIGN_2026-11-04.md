# 한 시즌 재미 보완 실행 설계 · 2026-11-04

사용자가 승인한 재미 검토 보고서의 P0/P1과 일반 결과 모달 정리를 한 묶음으로 구현한다. v2.7.0 / 빌드19 로컬 업데이트다.

- 계약: 신규 성과급 옵션은 기존 기본급+10%를 유지한다. POG 기본제시 주급10%(최대10만원), 우승50%(최대50만원), 계약연도 누적은 기본제시 주급2회분/최대100만원. 과거 계약에는 소급하지 않는다. 확정 서명 뒤 적용하며 재열람은 지급하지 않는다.
- 엔딩: LCK 및 과거 KCL 실제 우승을 집계한다. 관계는 성인 양측19세와 실제 스토리Lv4를 충족해야 평생 약속 결말, 그 외는 실제 진도에 맞는 청춘·응원 결말. 우승이나 고백을 창작하지 않는다.
- 추천: 기존 성장 계산을 유지하면서 선택한 시즌 목표의 훈련/소통 부족을 보완한다. 가능한 데이트의 실제 비용·체력·주간 제한과 대상까지 안내한다. 다음 상대의 전력과 준비 이유는 실제 데이터로 표시한다.
- 대표3인: 지은은 생활·학교 축제, 하린은 리플레이와 자기 방송, 민아는 진로와 공개 상담회. 건전한 공개 장소의 약속→일정 충돌→후속 만남3단계를 기존 데이트 비용·보상 안에 구현한다. 약속에 필요한 실제 준비를 해오면 이행 선택, 아니면 변경/사과 선택으로 이어진다. 새 선택 의미만 별도 저장하고 기존 storyChoices는 보존한다. 성인 원문 보호 경계는 유지하며 명시적으로 작성한 안전 장면만 통과시킨다.
- 리듬: 일반 주간 정산은 홈 카드, 상세는 재열람. 계약/서사/시즌결산 등 판단 장면은 유지한다. 주간 저장 트랜잭션을 변경하지 않는다.
- 화면: 기존 초상화와 CSS/SVG를 이용해 밝은 slate/blue/lavender로 통일한다. 짧은 등장·숫자 모션은 모션 줄이기를 존중한다. 이미지 추가 없으면 원본 이중배치를 건드리지 않는다.
