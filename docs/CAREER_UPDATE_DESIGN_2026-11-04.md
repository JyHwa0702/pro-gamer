# 2차 업데이트 기획 — 내 자리와 다음 팀

2026-11-04 · 사용자 승인: 주전 경쟁·잔류/이적·인연의 선택 기억을 하나의 커리어로 구현하고 돈·인기를 확장한다. 결과 색상/숫자 연출을 함께 추가한다.

## 플레이 경험

실제 주전 경쟁 기준과 최근 폼을 보고 준비한다 → 시즌 중 잔류/도전/생활 균형의 방향을 정한다 → 실제 스토브리그 제안을 비교한다 → 확정한 선택을 동행 인연에게 설명한다 → 다음 시즌이 그 약속과 선택을 기억한다.

| 구간 | 구현 | 선택의 의미 |
|---|---|---|
| 주간 준비 | 현재OVR·팀 주전 기준·최근3경기·코칭 평가 | 기존 콜업 기준까지 필요한 성장과 부진 회복 과제 확인 |
| 시즌 중반~서머 결산 | 시즌당1회 커리어 방향 선택 | 현 팀에서 증명/새 팀 도전/조건과 생활 균형을 기록 |
| 계약 | 실제 제안에 주급·전력·주전 경쟁 기준·현재 선수와의 격차 표시 | 제안 생성·급여·협상 확률을 유지하면서 비교 가능 |
| 계약 이후 | 확정된 재계약·이적·강등·콜업을 기록 | 계획과 실제 결과를 구분하고 인연 반응에 연결 |
| 다음 시즌 | 이전 계약·약속·인연의 선택 기억 | 같은 계약도 이전 관계 스타일에 따라 반응과 후일담 변화 |

## 주전 경쟁과 밸런스 경계

아카데미의 실제 콜업은 기존 `OVR >= starter-1`과 기존 확률을 사용한다. 1군의 경쟁 평가는 현재 전력 격차·최근3경기 폼을 보여준다. 코칭 평가는 훈련과 실제 경기 결과로 주1회 갱신되는 서사 상태이며, 기존 경기 확률·주전 출전·급여를 몰래 바꾸지 않는다. 부진하면 준비 과제와 대화가 달라진다. 강제 벤치로 기존 세이브의 경기 기회를 빼앗는 변경은 하지 않는다.

잔류 의향은 구단의 제안을 강제로 생성하지 않는다. 약속과 실제 계약이 다르면 ‘계획 변경’으로 정리하며 자산·팬·능력치를 소급 차감하지 않는다. 구단이 재계약을 제안하지 못한 경우와 플레이어가 새 팀을 고른 경우를 구분한다.

## 23인 선택 기억

23인 모두 잔류·이적·부진에 대한 고유한 짧은 반응을 가진다. 상대의 관심사(경기, 건강, 팀, 커리어, 생활, 독립성 등)에 맞추고 기존 캐릭터 말투/설정을 보존한다.

기존 `storyChoices`와 `relationshipStyle`을 읽어 ‘공감하며 함께함/서로의 방식 존중’으로 안전하게 요약한다. 과거 선택이 없는 세이브에는 과거 기억을 만들어 넣지 않는다. 새 계약 후 선택과 시즌 답변은 인물별 최근12개 기억에 저장하며 재열람은 읽기 전용이다. 미성년 구간에서 원래 성인 선택지나CG를 다시 출력하지 않는다.

## 돈·인기 확장

| 활동 | 비용·조건 | 효과·상한 |
|---|---|---|
| 개인 분석 리포트 | 아마5만/아카데미30만/1군200만원 또는 현금1% 중 큰 금액 | 코칭 평가+4(100상한), 스트레스-3, 시즌1회. 능력치·계약 확률 직접 가산 없음 |
| 이적 정착 지원 | 실제 확정 이적 후, 최소20만/1군100만원 또는 현금0.5% | 체력+8·스트레스-8·팀 호흡 최대+0.2. 시즌1회이면서 같은 이적에 평생1회, 다음 시즌에도 중복 불가 |
| 브랜드 공동 기획 | 팬1만·OVR60, 체력10·스트레스+8 | 팬과 실력에 비례한 협업 수입, 최대150만원/시즌. 팬 차감 없음 |

기존 활동4종을 보존한다. 새 활동3종은 명시적 실행·확인·실행 시 재검사, 저장·중복 제한을 적용한다. 기존 인터뷰와 브랜드를 합쳐 새 협업 직접 수익은 연간 최대200만원이다. 고액 자산이 있어도 효과는 같은 상한을 갖는다.

## UI와 결과 연출

시즌 허브에 ‘커리어’ 탭을 추가하고 주전 평가·약속·계약 경력·인연 기억을 연결한다. 계약은 정보를 짧은 비교 카드로 보여주고 기존 선택 순서는 유지한다.

주간/시즌 결산은 성장·수입·팬 증가를 긍정색, 소모·하락을 주의색, 변화0을 중립색으로 표시한다. 스트레스는 감소가 긍정이다. 숫자는640ms 이내에 표시 목표까지 증가하고 원래 최종 문자열을 정확히 복원한다. `prefers-reduced-motion`에서는 즉시 최종 값과 색상만 보인다. 소리나 상태 변경은 없다.

## 저장·아키텍처·검수

- Vanilla단일HTML/PWA·저장 키·기존 세이브·데이트/SNS 제한 유지. 새 `career`는 null-safe 선택 상태다. 손상된 새 필드만 복구한다.
- 코칭 주간 평가·계약·약속·인연 기억은 중복 키와 보존 개수 제한을 둔다. 기존 시즌 아카이브는 새 커리어 요약이 없어도 읽는다.
- 진행 중 체크포인트/완료 확정 저장을 유지해 대화·계약·결산 중 새로고침으로 지급/선택이 중복되지 않게 한다.
- 기본 경로는2.5.0과 기존 실질 상태·주가·난수 일치. 새 활동은 비용/체력/스트레스/코칭 상한·조건·반복·새 시즌·같은 이적 재사용을 검사한다.
- 아마/아카데미/1군, 부진·콜업·재계약·국내/해외 이적·취소·강등·새 커리어 경계와 실제26주 흐름을 검사한다.
- 모션은 중간 프레임·최종 숫자·색상 의미·재연출 방지·모션 줄이기·상태 불변을 검사한다.
- 버전2.6.0/18 동기화. 커밋·push·배포·APK 재빌드는 별도 요청 전 수행하지 않는다.
