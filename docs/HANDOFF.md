## 🎯 1. 프로젝트 개요 & 핵심 사용자

### 1-1. 프로젝트 목적
**'켠김에 GOAT까지 (Road to Worlds)'**는 17세 흙수저 솔랭 전사에서 시작하여 LoL 챔피언스 코리아(LCK), 월드 챔피언십(월즈), 아시안게임 금메달을 거머쥐는 e스포츠 프로게이머 성장 서사와 23인의 다양한 히로인과의 인터랙티브 비주얼 노벨 로맨스를 결합한 **웹/모바일 단일 파일 시뮬레이션 게임**입니다.

### 1-2. 핵심 타깃 사용자
- **LoL 및 LCK e스포츠 팬**: 솔랭 티어 상승, 팀 스크림, 밴픽 심리전, 포지션별 훈련, 월즈 스위스 스테이지 및 결승전의 현장감을 즐기는 유저.
- **인터랙티브 스토리 & 서브컬처 유저**: 23인 멀티 히로인(소꿉친구, 걸그룹, 스트리머, 코치, 해외 선수, 유명 연예인 모티브 등)과의 교감, 호감도 성장, 데이트, 동거 및 고유 패시브 버프 수집을 선호하는 유저.
- **방치형/타이쿤 자산 증식 유저**: 연봉 협상, 럭셔리 부동산(원룸~UN빌리지 펜트하우스), 슈퍼카 수집, 테크/e스포츠 주식 단타, 팬클럽 비즈니스를 통해 부를 축적하고 은퇴 후 2회차 구단주 모드로 진입하는 유저.

## 🧭 2. 요구사항 및 상태 구분 매트릭스 (확정 / 제안 / 미결정)

Codex 및 후속 개발자는 아래 분류를 엄격히 준수하여 작업해야 합니다:

### [A] 사용자가 직접 확정한 요구사항 (User Confirmed)
1. **미성년자 성적 장면 엄격 배제**:
   - 미성년자 나이 구간에서는 성적 대사/노출 의상 전면 배제 (건전 청춘 로맨스만 허용).
   - 작중 년도가 지나 성인 나이(19세 이상)가 도달한 이후에만 성인용 특이점 복장 및 무드 해금.
2. **히로인 이미지 무결성 전수 검증**:
   - 히로인 사진이 누락되어 회색 기본 아이콘(`icon-512.png`)으로 뜨는 현상 전면 차단.
   - 모든 히로인 이미지는 세로 전신/상반신 웹툰풍 고화질 일러스트로 제공되며, 루트 및 `assets/`에 이중 배치.
3. **주간 데이트 횟수 제한**:
   - 데이트 무제한 진행을 방지하고 주간 1회로 제한하여 턴 전략성과 긴장감 유지.
4. **리얼 인스타그램(GamerGram) 앱 UI**:
   - 앨범 사진 선택 + 6종 감성 필터 실시간 적용 + 해시태그 칩 + 인연 태그 기능.
   - 선수 능력치(OVR), 인지도 및 팬 수에 비례한 현실적 좋아요/댓글 산출 (무명 시절 대량 좋아요 방지).
   - 모르는 사람(스폰서, 열혈 수험생 팬, 익명 악플러, 해외 팬덤, 인플루언서) DM 유입 시스템.
5. **히로인 10인 확장 (연예인 모티브)**:
   - 카리나, 장원영, 아이유, 아이린, 채원, 수지, 윈터, 미연, 지젤, 한소희 모티브 히로인 추가 (총 23인 체제 완성).
6. **돈과 팬의 쓰임새 확장 (럭셔리 마켓)**:
   - 5단계 부동산 매매 (고시원 -> 오피스텔 -> 아파트 -> UN빌리지 펜트하우스 -> 성북동 대저택).
   - 5단계 슈퍼카 매매 (대중교통 -> 제네시스 G80 -> 포르쉐 911 -> 페라리 SF90 -> 롤스로이스 팬텀).
   - 팬덤 비즈니스 (공식 팬클럽 창단, 단독 팬미팅, 롤파크 서포터즈 결성, 1억 자선 기부).
7. **대형 시네마틱 돌발 이벤트 & 히로인 표정/대사 반응 연출**:
   - 디스패치 파파라치 기습 촬영, 롤파크역 지하철 전광판 조공, 커피차/한우 도시락, 인천공항 마비 사태 등.
   - 16:9 와이드 배너 일러스트와 함께 말을 거는 히로인의 초상화 및 감정 무드링(`mood-shock`, `mood-blush`, `mood-happy` 등) 시각화.

### [B] AI가 제안만 한 아이디어 (AI Proposals - 미확정)
1. **히로인과의 비밀 결혼식 & 가족 시스템**:
   - 은퇴 후 2회차에서 히로인과 결혼식을 올리고 2세 선수를 육성하는 유전 스탯 시스템 (아이디어 제안 단계).
2. **AI 대화형 LLM 채팅 연동 (AI SDK / Gateway)**:
   - 인스타 DM에서 실제 생성형 AI와 프리 토킹을 나누는 기능 (제안되었으나 순수 클라이언트 독립 실행 원칙 유지를 위해 미도입).
3. **음성 더빙(TTS) 지원**:
   - 주요 컷씬 및 데이트 대사에 Web Speech API 또는 사전 녹음된 효과음 보이스 적용 아이디어 (제안 단계).

### [C] 아직 결정되지 않은 사항 / 오픈 이슈 (Undecided)
1. **신규 10인 히로인의 성인 나이트 의상(CG) 제작 여부**:
   - 기존 13인 히로인은 기본/나이트 의상 분기가 마련되어 있으나, 신규 10인은 기본 고화질 초상화만 구비됨. 추가 나이트 전신 CG를 생성/탑재할지 여부 미결정.
2. **구단주 모드(2회차) 세부 드래프트/FA 연봉 밸런스**:
   - 2회차 구단주 모드의 AI 구단 간 영입 경쟁 알고리즘 심화 여부.

### 5-2. 실행 및 검증 명령어

#### 1) 로컬 개발 서버 실행
```bash
# Node 환경
npx serve . -p 5500

# 또는 Python 환경
python -m http.server 5500
```
- 접속 주소: `http://localhost:5500`

#### 2) 파이프라인 5단계 무결성 자동 검증 (필수)
```bash
node verify_pipeline.js
```
- 통과 시 `[SUCCESS: ALL TESTS PASSED] 5-Stage Pipeline Rules 100% Satisfied.` 출력 확인.

#### 3) 안드로이드 APK 및 AAB 빌드
```bash
# APK 빌드 (pro-gamer.apk 생성)
python build_apk.py

# 구글 플레이 배포용 AAB 빌드 (pro-gamer.aab 생성)
python build_aab.py
```

### 5-3. 필요한 환경변수 명칭 (보안 준수: 실제 키 미포함)
빌드 스크립트 실행 시 다음 환경변수 또는 로컬 경로가 필요합니다:
- `JAVA_HOME` 또는 `C:\Program Files\Java\jdk-17`: Java 17 SDK 경로
- `ANDROID_HOME` 또는 Unity 내장 SDK 경로: `build-tools/36.0.0`, `platforms/android-35`
- (깃허브 배포 시): `GITHUB_TOKEN` (GitHub Actions CI/CD 사용 시 필요, 현재는 master 푸시 방식)
