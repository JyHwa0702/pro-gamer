# UI UX 개선 및 다음 기획 보고서

2026년 11월 3일 · 로컬 v2.3.0 / 빌드15

## 이번에 적용한 방향

**홈에서는 이번 주에 할 일을 빠르게 고르고, 자세한 수치와 설명은 필요할 때 펼쳐보도록 정리했다.** 기존 단일 파일 게임과 다크톤을 유지하면서 홈·생성·인연·모달·상점·자산 화면의 간격, 버튼, 색상, 포커스를 통일했다.

반복되는 안내는 아이콘과 숫자, 상태 배지, 펼침 패널로 바꿨다. 비용·행동 조건·주간 제한·이야기 대사는 플레이 판단에 필요하므로 보존했다. 낯선 아이콘만으로 메뉴를 구성하지 않고 짧은 한글 이름을 함께 제공했다. 새로운 이모지를 과도하게 추가하지 않았다.

## 적용 범위

| 화면 | 이전의 불편 | 적용 내용 |
| --- | --- | --- |
| 홈 | 프로필·컨디션·안내·추천이 중복되고 메뉴가 본문 끝에 있음 | 커리어 요약→이번 주→일정 선택 순서. 하단6개 메뉴를 본문에서 분리 |
| 일정 | 긴 행동 설명과 여러 추천 버튼 | 대표 추천 버튼1개, 행동 아이콘·체력·스트레스·비용 칩. 상세 효과는 펼침 |
| 상태 | 체력/스트레스를 여러 곳에서 반복 | 상단 자원 요약으로 통합. 위험한 상태에서만 추가 안내 |
| 능력치·로드맵 | 항상 큰 영역을 차지 | 펼침 패널. 성장 로드맵은5개 단계 표시 |
| 홈 인연 | 미해금 인물까지23인 가로 목록 | 해금된 주요 인연 최대6명과 연락 상태. 전체 목록으로 연결 |
| 전체 인연 | 인물마다 긴 소개·패시브·조건 목록 | 초상화 카드. 이름·나이·호감도 우선, 효과/해금 조건은 펼침 |
| 인연 복귀 | 목록에서 대화 후 위치를 잃기 쉬움 | 대화에서 돌아올 때 목록 스크롤 위치 복원 |
| 상점·자산 | 상품 정보와 구매 버튼에 같은 내용 반복 | 거래/구매 선택은 바로 표시하고 시세·보유 내역·효과는 펼침 |
| 기록 | 순위와 개인 기록 경로가 분산 | 하단 기록에서 리그 순위와 나의 커리어를 함께 선택 |
| 생성 | 선택지별 설명과 보조 다운로드 안내가 길게 노출 | 단계 표시와 선택한 특성 강조, 세부 스탯·설치 안내 접기 |
| 생성 미리보기 | 특성 적용 전 OVR을 표시 | 실제 선택한 특성을 반영한 시작 OVR·현금·팬 미리보기 |
| 모달 | 긴 화면에서 닫기 접근과 포커스 복귀가 불편 | 스크롤해도 닫기 유지, Escape 닫기, 탭 순환, 배경 클릭 차단, 원래 메뉴 포커스 복원 |
| 데스크톱 | 모바일 폭을 그대로 늘려 사용 | 일정/행동과 인연/스탯을 나눈2열 대시보드 |

사진은 기존 캐릭터 초상화와 챔피언 에셋을 활용했다. 오래된 인원/배포 문구가 들어 있는 기존 홍보 이미지는 새 UI에 사용하지 않았다. 공통 아이콘은 인라인 SVG이므로 외부 라이브러리 요청 없이 표시된다.

## 검증

- Node 회귀 검사70개 통과. 기존 성장·연령·세이브·보상 검사65개를 포함한다.
- `node verify_pipeline.js`: `[SUCCESS: ALL TESTS PASSED]`.
- 별도 `vm.Script` 구문 검사: `SYNTAX_OK`.
- 320/390/1100px에서 홈·생성 화면의 가로 넘침과 하단 메뉴 겹침을 확인했다.
- 일정 필터, 능력치 펼침,23인 카드, 실제 데이트 비용 표시, 기록/커리어, 자산/스킨 탭, Escape·포커스 복귀를 브라우저에서 확인했다.
- 기존 인스타 작성/사진/필터/공유·모의 키보드 높이 변화도 재검사했다.
- 세이브·자산·수동 경기·연령 보호·캐시된 게임의 오프라인 재개는 별도 기존 흐름으로 회귀 확인했다. 최종 실행 증거는 `UI_UX_VALIDATION_2026-11-03.json`에 기록한다.

버전은 `index.html`, `sw.js`, 루트/assets `version.json`을 v2.3.0·15로 맞췄다. 기존 세이브 키·주간 보상·데이트 횟수·연령 규칙은 유지했다. 배포·APK/ZIP 재빌드는 하지 않았다. 실제 휴대전화 가상 키보드와 설치형 PWA의 기기별 확인은 남아 있다.

## 다음 기획 제안

아래 항목은 다음 개발을 위한 제안이며 이번 UI 변경에 구현된 기능은 아니다.

### 1순위 주간 결과 브리핑

**목적:** 행동을 누른 뒤 무엇이 달라졌고 다음에 무엇을 하면 좋은지 짧게 보여준다. 단순히 수치를 반복하는 팝업보다 결과의 의미를 전달한다.

- 한 장의 결과 카드에 경기 승패/성장/컨디션/현금 변화를 아이콘과 전후 숫자로 표시.
- 중요한 사건1개와 다음 목표1개를 함께 제시. 예: 다이아까지 남은 LP, 입단 조건 진행, 다음 주 상대.
- 일반 정산은 한 번에 요약하고 중요한 인연 장면·대회 컷씬은 별도 감상 가능하게 연결.
- 기존 정산 함수의 실제 결과만 사용한다. UI에서 보상을 다시 계산하거나 지급하지 않는다.

**검수 기준:** 한 주 진행에 중복 지급0건, 요약과 실제 세이브 수치 일치, 모든 보상·중요 사건의 상세 기록 확인 가능. 서사를 건너뛰어야만 빠른 진행이 가능한 구조를 만들지 않는다.

### 2순위 시즌 목표와 대회 흐름

**목적:** 매주 훈련을 반복하는 가운데 시즌 전체의 목표와 긴장감을 보여준다.

- 스프링→플레이오프→서머→월즈→계약의 진행 위치를 게임의26주 일정에 맞춰 표시.
- 이번 상대·내 팀 순위·플레이오프/월즈 조건을 시즌 카드에서 확인.
- 지금 성장시키면 좋은 능력치1개와 이를 선택하는 이유를 짧게 제안.
- 기존 대회 규칙과 데이터를 사용하며, 실제 리그의 최신 제도를 따르는 것처럼 안내하지 않는다.

**검수 기준:** 일정과 실제 경기 실행이 일치하고, 탈락·계약·비시즌 상태를 정확히 표시. 재로드 후 목표·진행 위치 보존.

### 3순위 인연의 선택 기억

**목적:** 호감도 숫자 외에 이 인물과 무엇을 함께했고 어떤 선택을 했는지 체감하게 한다.

- 이미 저장하는 `storyChoices`, 관계 스타일, 인연 레벨을 인물별 타임라인에 표시.
- 선수의 첫 우승·부진·콜업과 인물의 관심사를 연결한 반응을 단계적으로 추가.
- 캐릭터마다 기억되는 선택1개와 후일담 차이1개부터 연결.
- 미성년 구간은 공개 장소 대화·응원·청춘 서사로 구성하고, 이미지/선택지에도 동일한 연령 조건 적용.

**검수 기준:** 선택 기록과 후일담이 일치하며, 새 커리어/구버전 로드/나이 경계에서 다른 회차의 내용이 섞이지 않음.

### 이후 구단주 로스터와 FA

앞의 주간·시즌 흐름이 정리된 뒤 별도 기획으로 확장하는 것이 좋다.

- 현재 유망주 후원·코칭 회차에서5인 로스터 운영으로 넘어가는 범위를 명확히 정의.
- 첫 MVP는 FA 후보 비교, 한도 있는 연봉 협상, 계약 후4주 예산 전망으로 제한.
- 전력만 올리는 정답 선수보다 즉시 전력/성장형/저비용 역할의 차이를 만든다.
- 자본·주간 고정비·성장 속도·기존 회차 세이브 전환을 먼저 검증한 뒤 이벤트와 후보 수를 확장.

## 권고

다음 구현은 주간 결과 브리핑부터 진행하는 것을 권한다. 현재 있는 훈련·경기·인연·자산의 결과를 한 화면에서 이해하게 만들면, 이후 시즌 목표와 관계 기억을 자연스럽게 붙일 수 있다. 신규 인물과 의상을 더 늘리는 작업은 기존 인물의 만남·반응·후일담이 충분히 체감되는지 확인한 뒤 진행한다.
