# 기존 화면 완성도 보강 결과

2026-11-05 · 로컬 v2.9.1 / 코드23 · 미배포

## 무엇을 보강했나

새 시스템을 추가하지 않고 기존 화면을 보강했다. 현재 주요 화면에서 큰 가로 넘침은 재현되지 않았으며, 실제로 확인한 표시 취약점과 정보가 길게 이어지는 화면을 중심으로 수정했다.

| 대상 | 변경 |
|---|---|
| 커리어 기록 | 현재 챔피언·선수 프로필, 경기·승률·POG·최고 티어·월즈·주급 카드로 요약. 사건은 최신 6개 타임라인과 이전 사건 펼치기로 정리. 모든 원본 사건과 은퇴 동작 유지 |
| 시즌 여정 | 현재 선수·챔피언 이미지와 랭크·입단·1군·월즈 달성 기록을 배치. 기존 목표·코칭·인연·일정 내용 유지 |
| 이미지 누락 대응 | 일부 SNS·갤러리·밴픽·시네마틱의 같은 이미지 재요청을 유한한 fallback으로 교체. 구세이브의 손상된 현재 챔피언도 표시 단계에서 복원 |
| 랭킹 | 밝은 표 헤더, 고정 헤더·교차 행 배경·긴 이름 줄바꿈으로 읽기 쉽게 정리 |
| 좁은 화면 | SNS 프로필 최소 너비·줄바꿈과 긴 버튼/기록 문구 처리 보강. 기존 하단 메뉴·모달 닫기 유지 |
| 이미지 확대 | 새 시즌·커리어 챔피언도 기존 확대 보기 사용. 실제 표시된 이미지 확대, 선택·세이브와 분리 |

기존 인물·장면 에셋을 재사용했다. 새 캐릭터 이미지나 콘텐츠를 생성하지 않았다. 저장키·신규 상태 필드·보상·경기 판정·연애 제한·연령 조건은 변경하지 않았다.

| 패키지 보존 | APK/AAB/ZIP SHA-256 기존 값과 일치. 재빌드하지 않음 |

브라우저의 의도적 실패 검사는 SW·이미지 메모리 캐시가 404를 가리지 않도록 별도 컨텍스트에서 실행했다. 정상 오프라인 검사는 SW가 있는 컨텍스트에서 따로 확인했다. 초기 검사 중 대화창 숨김 대기와 밴픽 후 챔피언 변경, 캐시 준비 조건을 바로잡았으며, 이를 제품 결함 수정으로 계산하지 않았다. 기존 시리즈 회귀 검사의 v2.9.0 고정값은 온라인에서 실행하던 버전과 오프라인 복원 버전이 일치하는지 비교하도록 변경했다. 옛 연령/수동 경기 검사의 수동 기본 전제도 현재 시리즈의 명시적 수동 모드와 밴픽→전체자동 흐름으로 갱신했다.

표준 파이프라인은 기존 Android 패키지의 존재·기본 무결성을 검사한다. 이번 웹 변경이 Android 패키지 안에 들어갔다는 뜻은 아니다. 실제 Android/iOS 기기·설치 PWA·모든 사용자 세이브·사람이 느끼는 재미를 전수 검증한 결과는 아니다.
