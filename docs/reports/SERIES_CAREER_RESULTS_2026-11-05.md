# 실제 다전제에서 다음 계약까지 · v2.9.0 결과

2026-11-05. **로컬 구현·검증 완료, 미배포.** 현재 공개 웹은 v2.8.0이다. Vanilla 단일 `index.html`과 오프라인 PWA를 유지했다.

## 완성한 흐름

**실제 세트별 밴픽/경기 → BO3/BO5 승부 확정 → 주전 평가 → 계약 근거 저장 → 시즌 결산**을 한 기록으로 연결했다. 기본은 완전자동이며 일반 시리즈를 진행할 때 확인창을 추가하지 않는다.

| 단계 | 새 동작 |
|---|---|
| 실제 시리즈 | 매 세트 드래프트·국면·QTE 판정. BO3는2승, BO5는3승에 바로 종료. 결과를 미리 정하거나 단판에 가상 스코어를 붙이지 않음 |
| 경기 방식 | 기본 자동. `더보기 → 경기 진행 방식`에서 직접 밴픽·국면 선택 가능. 도중 ‘남은 경기 자동’은 다음 세트와 해금 대화까지 처리 |
| 정산 | 시리즈당 경기기록1개·평점1개·체력8·숙련 총100. 숙련은 실제 사용한 챔피언에 나눠 지급 |
| 평가 | 전체 세트 평균이 시리즈 평점. 최근3시리즈와 현재 평가기간 평균을 구분하고 기존 콜업/경쟁 기준은 유지 |
| 계약 | 같은 평가기간 성과를 읽고, 제안 당시 경쟁 기준·OVR·평점·제시/최종급여를 스냅샷으로 보존. 이후 팀이나 능력치가 바뀌어도 과거 근거는 고정 |
| 기록/결산 | `기록 → 실제 시리즈 기록`에서 세트별 픽·승패·평점 확인. 결산은 시리즈/실제세트 승패와 계약 당시 근거를 함께 보관 |

정규리그BO3, 플레이오프 전 라운드·월즈 녹아웃/결승BO5를 호출부에서 명시했다. 기존 가상 월즈 그룹은BO1, 아시안게임 준결승BO3/결승BO5 정책이다. 가상26주 일정과 대회 구성을 유지하는 게임 정책이며 현행 LCK/월즈/아시안게임 전체 규정을 그대로 복제한 것은 아니다.

실제 세트 기록의 대상은 플레이어가 출전하는 공식전이다. 다른 구단끼리의 경기는 기존 간이 시뮬레이션을 유지해 기존 리그 밸런스의 범위를 보존했다.

## 세이브와 보상 보호

- v4/v3/v2/v1/progamer_save5개 키, 기존 친분·혼인·계약·평점·자산·시즌 아카이브를 보존한다. 신규필드 `seriesHistory`/`seriesSequence`/`seriesPreferences`는 기본값과 손상 복구를 사용한다.
- 기존 `hist.games/wins`, 라이벌, 주간 기록, 시즌 목표는 계속 **시리즈 단위**다. 업데이트 전 기록에 실제 세트를 추정해 붙이지 않는다. 과거 구간은 ‘세트 상세 없음’으로 구분한다.
- 최근120개 시리즈를 보관한다. 기록이 범위 밖으로 밀려나도 확정 시퀀스와 선수 소유권 검사로 재지급을 막는다. 122시리즈 실행 시 기록120개·공식전122개·숙련총12,200을 확인했다.
- 주간 시작 전 체크포인트/주간 완료 확정 저장을 유지한다. 세트 중간에는 돈·업적·영구 성장·부분 저장을 확정하지 않는다. 새로고침하면 시작 전 상태로 돌아간다.
- QTE 임시 성장으로 업적이 먼저 지급되는 경계를 독립 리뷰에서 재현해 수정했다. 비대표 세트의 임시 성장에 업적 성장까지 섞여 사라지는 문제도 검사했다. 최종 시리즈에서 업적·보상은1회 확정한다.
- 기존 체력·기본성장·급여 수식, 콜업60%·구단 제안55%/60%와 경쟁 임계값, 성과급 금액·연간 한도는 유지했다. 실제 BO5의 POG 성과급1회·재로드 후 중복 무효도 별도 검사했다.
- 연인1+썸2·데이트주1회·SNS주간상한·미성년 보호를 변경하지 않았다. 새 이미지나 프레임워크를 추가하지 않았다.

## 밸런스 검증

독립 세트 확률을 그대로 반복하면 기존80%는BO5 약94.2%가 된다. 기존 난이도에 가깝게 유지하려고 단판의 마지막 판정 확률에 대칭 보정을 적용했다. 기준 커널75,000개의 확률 관측으로 BO3계수0.90/BO5계수0.88을 선택하고, 이후 실제 시리즈를 별도 실행했다. 단판 커널과 독립 세트, 모든 과거 결과를 동시에 완전히 동일하게 만들었다고 주장하지 않는다.

| 검증 | 실행과 결과 |
|---|---|
| 실제 경기 비교 | 기존30,000경기 + 신규60,000시리즈 |
| 시리즈 승률 차이 | 기존 대비 최대 **BO3 2.35%p / BO5 2.50%p** |
| 동급 조건 | 모든 포지션45~60% 범위 |
| 정산 예산 | 모든 시리즈 체력−8·숙련총100·경기/평점1개 |
| 시즌 비교 | 기존90시즌과 신규90시즌, **180/180 완료·총4,680주** |
| 신규 실제 기록 | **1,185매치·3,000세트**, 선택 대기0·주간 저장 불일치0 |

시즌 실험은 미드·특성 없음·3전략×아마30/아카데미55/프로65×10시드다. 3전략을 합친 각 시작 상태30회 평균은 다음과 같다.

| 항목 | 아카데미55 · 기존→신규 | 프로65 · 기존→신규 |
|---|---:|---:|
| 최종 OVR | 75.286 → 75.201 | 80.432 → 80.722 |
| 현금 | 2.589억 → 2.558억 | 3.051억 → 3.075억 |
| 팬 | 11.13만 → 12.02만 | 9.73만 → 9.27만 |
| POG | 9.00 → 9.17 | 5.07 → 4.57 |
| 공식전 승률 | 69.52% → 69.75% | 45.58% → 43.73% |
| 최종 프로 | 30/30 → 30/30 | 30/30 → 30/30 |
| 계약 기록 수 | 60 → 60 | 30 → 30 |

아마추어 시작은 모든 집계가 같았다. 신규 세트가 추가 난수를 사용하므로 이후 대진·업적·일정과 개별 시즌은 달라질 수 있다. 위 평균이 모든 조건의 완전 동일성을 뜻하지 않는다. **프로 시작 조건의 POG 평균은 약10% 낮아진 편차가 남는다.** 실제 세트 평균으로 극단적 평점이 줄어드는 효과와 대표 활약 선발을 구분해 측정했다. 이 편차와 실제 첫 플레이의 체감은 후속 확인 대상이다.

시즌 자동 정책은 일반 계약을 선택해 양쪽 인센티브 지급액이0이었다. 이 실험만으로 성과급 경로까지 확인했다고 주장하지 않고, 별도의 실제 BO5 정산 테스트에서 성과급1회·한도·재지급 차단을 확인했다.

## 남은 범위와 다음 방향

이번 버전은 실제 BO3/BO5이며 **피어리스는 미지원**이다. 45명·역할당9명 풀에서는5세트 양팀의 역할당10픽도 채울 수 없으므로, 별도 풀/복수 포지션 설계 없이 피어리스를 구현했다고 하지 않는다.
