# 한 시즌 통합 업데이트 결과

**로컬 v2.5.0 / 빌드17 · 2026-11-03 작업**

선수 성장과 인연 서사를 균형 있게 발전시키는 장기 기획을 작성하고, 1차를 개막부터26주 결산까지 이어지는 플레이로 구현했다. 돈·인기가 준비·팬 활동·협업·관계의 선택에 쓰이도록 연결했다.

## 이번에 완성한 시즌 흐름

| 시점 | 플레이 |
|---|---|
| 개막/구세이브 합류 | 도전·기본기·균형 중 목표, 해금 인연 중 동행자 선택 |
| 매주 | 기존 일정·경기 진행, 목표 진행·실제 순위/다음 상대·라이벌 결과 확인 |
| 9주 | 스프링 평가와 동행자의 반응, 회고/계획 선택 |
| 12주 | 서머 준비와 라이벌 대응 방식 선택 |
| 20주 | 서머 결과와 자신감/감사의 선택 |
| 23주 | 실제 월즈 진출·우승·관전 상태에 맞춘 회고 |
| 24주 | 기존 스토브리그 결과가 시즌 상태·현금·소속·기록에 반영 |
| 26주 | 목표·공식전·성장·현금·팬·활동 지출·선택·후일담 결산 |
| 다음 시즌 | 이전 동행과 마지막 약속을 개막에서 다시 확인 |

홈 시즌 카드와 `시즌 보기 → 시즌/준비·활동/기억`, `기록 → 시즌 결산`을 연결했다. 큰 금액은 요약하고 정확한 값은 상세에 둔다. 긴 후일담은 짧은 본문과 전체 기록으로 나눴다.

지은·하린·민아는 각자의 관심사에 맞는 시즌 대사와 후일담을 제공한다. 나머지20명도 해금 상태에서 동행자로 선택하고 공통 시즌 반응을 볼 수 있다. 기존23인 이야기·데이트·선물은 보존했다. 새 대사는 미성년 구간에도 공개 응원·경기·일상만 다루며 성적 연출/접촉/신규 의상을 추가하지 않았다.

## 돈·인기의 활용

| 선택 | 조건과 비용 | 적용 효과 |
|---|---|---|
| 훈련 환경 지원 | 아마3만/아카데미25만/1군100만원과 보유 현금1% 중 큰 금액 | 체력+6, 스트레스-6, 기존 팀 호흡5 미만이면 최대+0.3 |
| 팬 초청 공개행사 | 팬1000·OVR40, 최소10만원 또는 현금0.5%, 체력8 | 팬 최대+300, 스트레스-4 |
| 인터뷰 협업 | 팬500·OVR40, 체력6·스트레스+6 | 팬 수·OVR에 따른 출연료, 최대50만원 |
| 동행 기록집 | 최소5만원 또는 현금0.2% | 호감도 정확히+2(100상한), 접촉 기록·기존 경계 보너스 동기화, 전용 후일담 |

각 종류는 시즌당1회이며 별도 주차를 진행하지 않는다. 실행 확인창에 비용·조건·효과를 표시하고 실행 시 다시 검사한다. 취소·재열람은 무소모다. 팬 수는 화폐처럼 차감하지 않고 기회를 여는 조건으로 쓴다. 체력·스트레스에는 기존 기어·인연 효과가 적용된다.

기존 주거·차량·기어·주식·임대·팬클럽·선물의 활용 설명과 자산/상점 진입도 시즌 활동에 연결했다. 목표 달성은 시즌 기록으로 남기며 현금·가짜 우승·영구 스탯을 추가 지급하지 않는다.

## 기존 세이브와 정산

- 기존5종 저장 키와 선수·자산·주식 가격·인연·알 수 없는 필드는 유지했다.
- `seasonJourney`와 `seasonArchive`만 선택 필드로 추가했다. 누락·null·중첩 손상은 해당 신규 기록만 복구한다.
- 중간 합류는 현재 주부터 기록하고 남은 기간에 맞춰 목표를 정한다. 과거 실패·미완료 대사를 소급 생성하지 않는다.
- 진행 중에는 주간 시작 전 체크포인트를 유지하고, 완료한 주와 브리핑을 함께 확정한다. 결산 도중 새로고침해서 훈련을 두 번 받는 문제를 차단했다.
- 자연 은퇴 전 마지막 시즌을 기록하고 새 커리어/구단주 후원 회차와 분리한다. 결산은 최근12시즌을 보존한다.
- 라이벌은 실제 첫 국내 공식 상대를 리그와 팀ID로 식별한다. 아카데미와1군의 같은 숫자ID를 합산하지 않는다.

지정 정책: 기본 특성·기존 추천 일정·빠른 경기, 활동군은 매년 첫 주에 실행 가능한 활동을 각1회 시도했다. 두 군 각25개 커리어이며 서로 같은 시작 시드를 썼다.

활동 이후 컨디션·관계와 경기 결과, 이후 난수 경로가 달라질 수 있으므로 최종 현금 차이를 활동의 직접 수익으로 해석하면 안 된다. 표의 직접 협업 수입과 별도로 구분했다. 이 표는 지정된 추천 정책에 대한 관찰이며, 모든 선택에서 같은 이득이나 승리를 보장하지 않는다.

## 플레이 검증에서 함께 수정한 표시 오류

기존 돌발 이벤트가 팀 호흡을5보다 높게 올리면 홈의 원형 표시에서 음수 `String.repeat()` 오류가 발생했다. 실제26주 브라우저에서 재현한 뒤 표시만 안전화하고 강화 수치도 텍스트로 보이게 했다. 기존 저장값·경기 계산은 유지했다. 새 지원 활동이 기존 강화 수치를 낮추지 않는 검사도 추가했다. 기존 강화 이벤트의 수치 정책 재조정은 별도 밸런스 변경이므로 이번에는 적용하지 않았다.

## 한계와 다음 큰 단계

- 실제 사용자 세이브 전체·모든 플레이 스타일을 검증한 것은 아니다. 실제 Android/iOS·OS 키보드·설치형PWA·APK 실행 검사는 남아 있다.
- 오프라인은 먼저 방문해 캐시한 로컬 게임의 재실행이다. 모든 에셋 사전 다운로드를 보장하지 않는다.
- 파이프라인 APK/ZIP 검사는 기존 파일 존재·크기 확인이다. 최신 APK/ZIP을 재빌드하지 않았다.
- 커밋·push·라이브 배포는 하지 않았다. 기존 미커밋 변경을 유지한 로컬 구현이다.
