# 경기부터 다음 시즌까지 — 보강 결과

2026-11-05 · 로컬 **v2.9.2 / 코드24** · **미배포**

**같은 조건의 26주 플레이에서 확인·선택이 28회 → 20회로 줄었고, 실제 선수 상태와 다음 난수는 유지됐다.** 줄어든 8건은 선택 없는 일반 알림으로, 주간 소식에서 다시 볼 수 있다. 완전자동 모드는 중간 입력 대기0으로 다음 시즌까지 완료됐다.

## 1. 한 시즌에서 달라진 점

| 흐름 | 보강 |
|---|---|
| 경기 전 | 실제 이번 주 상대·양 팀 전력·정규 BO3를 카드로 표시. 상세 전력 설명은 펼쳐 보기. 미정인 PO·월즈 상대를 지어내지 않음 |
| 경기 후 | 홈·주간 브리핑에 실제 시리즈 스코어·출전 챔피언·평균 평점·확정 POG를 같은 형식으로 표시. 세트별 상세는 추가 확인창 없이 펼쳐 보기 |
| 직접 경기 | 실제 선택 챔피언을 헤더에 표시하고 확대 가능. 한 세트의 해설에서 가상의0:2 시리즈 점수나 확정 전 POG를 말하던 표현 수정 |
| 대사·사진 | 인물·장소·기억 시점을 확인한 경우에만 함께 찍은 사진 재사용. 패배·아쉬움·사과에는 기존 건전한 걱정 표정 사용. 현재 장면을 다른 장소의 기억으로 덮지 않음 |
| 일반 알림 | 명시적으로 지정한 팬덤·컨디션·새 시즌 등의1버튼 알림은 주간 소식으로 모음. 제목은 접힌 상태에서도 표시하고 원문 내용은 펼쳐서 확인 |
| 중요한 선택 | 계약·관계·시즌 분기 및 다중 선택의 대기·선택지·정산 유지. 주간 진행 밖에서 직접 연 알림도 기존 대기 유지 |
| 시즌 결산 | 기존 목표·수치·인연 후일담과 함께, 보존된 실제 시즌 마지막 경기2개를 펼쳐서 회상. 기록이 없는 옛 세트·챔피언은 창작하지 않음 |

새 경기 규칙·보상·데이트 비용·횟수·연애 제한은 추가하거나 변경하지 않았다. 기존 이미지와 확대 기능을 사용했고 새 게임 에셋은 만들지 않았다.

## 3. 실제 26주 검증

| 시나리오 | 결과 |
|---|---|
| 수정 전·후 같은 프로 합성 선수, 시드101, 같은 추천 일정·첫 활성 선택 | 각각26주 → **2년차1주**, 공식23경기·12승11패 동일 |
| 주간 진행 중 확인·선택 | **28 → 20회**, 8건의 단순 확인을 주간 소식으로 이동 |
| 실질 상태·다음 난수 | **일치**. 돈·팬·스탯·컨디션·챔피언 숙련·경기·계약·인연·시즌 기록을 포함한 전체 상태 비교 |
| 프로 완전자동26주 | 공식23경기·결산·다음 시즌 완료. **중간 대화창0 / 미해결 선택0** |
| 실제 생성 화면에서 시작한 신인 | 이름·특성 선택→시작→자동26주→2년차1주, 브리핑26개·결산1개, 미해결 선택0 |

확인 횟수는 **주간 진행 중 발생한 확인·선택 버튼**을 센 것이다. 일정 진행26회와 검증용 재열람·확대 조작은 제외했다. 따라서 전체 사용자 조작 횟수가28→20이라는 뜻은 아니다. 계약·관계 등 실제 선택을 없애서 줄인 수치도 아니다.

신인 검증은 기존 밸런스대로 아마추어 상태에서 시즌을 마쳤고 공식 프로 경기 수는0이었다. 프로 경기·계약·월즈 흐름은 별도의 프로 합성 선수로 검사했다. 첫 시즌에 모든 이용자가 프로 진출·월즈 우승한다는 검증이 아니다.

비교에서 제외한 것은 새 표시 메타데이터 **`weeklyBriefingHistory[].notices`뿐**이다. 알림 보관 때문에 저장 문자열 전체의 바이트 동일성을 주장하지 않는다. 해당 메타데이터 없이 저장된 기존 기록은 빈 소식으로 표시하며, 손상된 소식 필드도 본래 선수 세이브를 버리지 않는다.

기존4 SKIP은 예전 기능별 기준 파일 환경변수를 지정해야 실행되는 선택 비교다. 이번 수정 직전 및 고정 커밋 비교는 위 별도 명령으로 실제 실행했다.

브라우저 검사에서 모달 뒤의 홈 요소를 선택하거나 열린 선택창의 Promise를 기다리던 검사 코드, 새 펼치기 추가로 모호해진 선택자를 바로잡았다. 이러한 검사 수정은 제품 결함 수정이나 확인 횟수 감소로 계산하지 않았다. 숫자 애니메이션·토스트가 끝난 뒤 비교 화면을 캡처했다.
