# 주간 결과 브리핑 구현 및 검증 보고서

2026-11-03 · 로컬 v2.4.0 / 빌드16

주간 결과 브리핑을 구현했다. 기존 행동·경기·경제 정산을 한 번 실행한 뒤 실제 상태의 전후 차이를 표시한다. 보상 수식, 성장량, 경기 확률, 주간 데이트·SNS 제한은 유지했다.

## 사용 흐름

1. 홈에서 이번 주 일정을 진행한다.
2. 경기 선택, 인연 장면, 대회와 주요 사건은 기존 흐름에서 확인한다.
3. 주간 종료 후 브리핑 한 장에서 OVR·현금·체력·스트레스·팬의 전후 값과 순변화, 공식 경기 승패, 중요 사건1개, 다음 목표1개를 본다.
4. `경기·성장·정산 상세`를 펼치면 개별 경기 평점/POG, 6종 성장, 랭크, 현금 구간별 합계, 업적·소속·인연 변화와 일정 로그를 확인한다.
5. 홈 `지난 주 브리핑` 또는 `기록 → 주간 브리핑`에서 최근26주를 재열람한다. 완료한 주차는 새 주차와 구분하여 표시한다.

아이콘과 전후 숫자를 중심으로 구성했고 긴 설명은 상세 패널에 두었다. 320/390/1100px 화면을 검사했다. 새 이미지·외부 폰트·네트워크 의존성은 추가하지 않았다.

## 세이브와 밸런스 보존 방식

- 기존 저장 키와 상태 필드는 유지한다. `weeklyBriefingHistory`만 선택 필드로 추가하고, 누락·null·형식 손상은 빈 기록으로 처리한다.
- 기록은 이번 구현 이후 완료한 주부터 생성한다. 기존 세이브의 과거 결과를 추정해서 채우지 않는다.
- 최근26개 기록을 보존하고 같은 연차/주차는 중복 저장하지 않는다. 선택 기록 일부가 손상돼도 정상 기록과 기존 선수 상태는 읽을 수 있다.
- 행동 전/직후/주간 종료 스냅샷을 관찰한다. 표시·닫기·재열람에서 성장·급여·상금·데이트·경기를 다시 실행하지 않는다.
- 기록과 완료된 주차를 함께 저장한 후 브리핑을 연다. 브리핑 중 일정 연타는 기존 busy 경계에서 차단한다.
- 자연 은퇴 직전 마지막 주를 기록하고, 새 선수/구단주 후원 회차에는 이전 선수의 기록을 붙이지 않는다.
- 솔랭 LP 갱신 중 동시에 시작된 인연 장면은 순차 표시하고 종료를 기다린다. 번아웃 LP 차감에서 생긴 해금도 번아웃 알림 전에 마친다. 후반 스킨·명예의 전당 알림도 종료 후 브리핑을 연다.
- 연령 보호는 기존 공통 렌더 경계에 그대로 적용된다. 기록에는 대사·CG를 복제하지 않고 인연 이름/레벨/호감도 변화만 저장한다.

## 검증의 한계와 현재 상태

- 624주는 지정 시드와 추천 일정에 대한 비교다. 모든 선택 조합을 증명하지 않는다. 실제 사용자의 세이브 전체를 확보해 검사한 것은 아니다.
- 실제 Android Chrome/iOS Safari와 OS 키보드, 설치형 PWA, APK 실행은 이번 검증에 포함되지 않는다.
- 오프라인 검사는 먼저 방문한 로컬 캐시의 재실행이다. 신규 설치 시 모든 에셋 사전 캐시를 증명하지 않는다.
- 파이프라인 APK/ZIP 검사는 기존 파일 존재·크기 확인이며 최신 코드 반영 검사가 아니다.
- 커밋·push·라이브 배포·APK/ZIP 재빌드는 하지 않았다. 기존 미커밋 작업을 유지한 로컬 구현이다.
