아카데미의 콜업 조건과 확률,1군 기존 출전, 경기/성장/급여·협상 수식은 유지했다. ‘폼 재정비/주전 경쟁/선발 평가 안정’은 실제 전력·최근 평점을 읽는 평가이며, 새 평가 수치로 기존 경기 기회를 박탈하지 않는다. 코칭 평가는 서사 기록으로만 사용한다.

## 인연의 선택 기억

- 23인 모두 잔류·이적·부진에 대한 고유한 짧은 반응을 추가했다.
- 기존 `storyChoices`와 관계 스타일을 ‘공감하며 함께함/서로의 방식 존중’으로 안전하게 요약한다. 기록이 없으면 과거를 만들어 넣지 않는다.
- 실제 시즌 답변과 계약 후 대화를 인물별 최근12개 기억으로 보존한다. 동행 기억은 시즌 커리어 탭, 각 인물의 기억은 인연 메뉴에서 읽는다.
- 인연의 관심사와 이전 선택을 반영한다. 예: 서예진은 조건/약속 확인, 백설아는 건강과 적응, 하린은 리플레이/역할을 중심으로 반응한다.
- 새 기억·계약 반응으로 호감도·데이트·성장 보상을 추가 지급하지 않는다. 미성년에게 원래 성인 선택지/CG를 재출력하지 않으며 새 대사는 전부 경기·진로·생활·응원이다.

## 돈·인기 확장

기존 활동4종과 자산/기어/주거/차량/팬클럽 경로를 유지하고 아래3종을 추가했다.

| 활동 | 조건/대가 | 효과·한도 |
|---|---|---|
| 개인 분석 리포트 | 아마5만/아카데미30만/1군200만원 또는 현금1% 중 큰 금액 | 코칭 평가+4(100상한), 스트레스-3, 시즌1회 |
| 이적 정착 지원 | 최근 실제 외부 이적, 최소20만/1군100만원 또는 현금0.5% | 체력+8·스트레스-8·팀 호흡 최대+0.2, 시즌1회이면서 같은 이적에1회 |
| 브랜드 공동 기획 | 팬1만·OVR60, 체력10·스트레스+8 | 팬과실력 비례 수입, 최대150만원/시즌 |

인기는 화폐로 차감하지 않는다. 돈이 많아도 효과 상한은 같다. 체력·스트레스에는 기존 효과를 적용하며, 높은 기존 팀 호흡을 지원 활동이 낮추지 않는다. 확인창에 정확한 비용·수입을 표시하고 실행 시 조건을 다시 확인한다. 같은 구단의 아카데미→1군은 외부 이적으로 보지 않아 정착 지원이 열리지 않는다. 연차가 바뀌어도 이미 쓴 같은 이적의 지원은 재사용할 수 없다.

## 결과 연출

주간 브리핑·시즌 결산·커리어 수치 카드에 DOM 전용 연출을 적용했다.

- 숫자는0부터 약640ms 동안 최종 표시값까지 증가한다. 쉼표·소수·부호·만/억 단위를 유지하고 최종 원문으로 정확히 복원한다.
- 증가/수입은 긍정색, 감소/손실은 주의색, 변화0은 중립색이다. 스트레스는 감소가 긍정이다. 비교 기준·현재 수치는 중립색으로 표시한다.
- 결과 카드에 짧은 등장/강조 효과를 적용하고 동일DOM을 반복 연출하지 않는다.
- 모션 줄이기 설정에서는 즉시 최종값을 보여준다. 실행 중 설정 변경과 요소 제거도 처리한다. 접근성 이름은 항상 최종 원문이다.
- 연출은 게임 상태·저장·난수에 접근하지 않는다. 별도 소리를 추가하지 않았다.

하위 에이전트는 결과 연출과 독립 검사를 담당했고, 루트는 커리어·자원·계약·통합 검증을 담당했다. 별도 검토 에이전트가 커리어 변경을 읽고 재현 검사했다.

동일25시작 조건을 양군에 사용했다. 기본 특성·기존 추천·빠른 경기, 제안2개이상이면 양군 모두 두번째 계약을 선택한다. 활동군은 매년1/25주 가능한7종 활동을 시도했다. 기존 업적을 포함한 게임 함수를 사용했다.

활동이 성장·돈·팬·승리를 모두 높이는 정답으로 나타나지는 않았다. 다만 지정 시드/정책의 관찰이다. 컨디션과 선택 이후 경기·난수 경로가 달라져 최종 자산 차이를 활동 직접 수익으로 해석할 수 없다. 직접 수익은 따로 집계했다. 모든 스타일에서 동등하거나 우월하다는 결론은 아니다.

극단적 명성·낮은 실력·돈/체력 부족·취소·busy·재로드·새 시즌·동일 이적·같은 슬롯 해외 교체도 별도 검사했다. 기존 인터뷰+브랜드의 직접 수입은 연간 최대200만원,3시즌 최대600만원이며 활동 횟수도 제한한다.

## 리뷰에서 수정한 경계

1. 동일 구단의 아카데미/1군을 외부 이적으로 취급하던 문제를 조직/경기 단계로 나눠 해결했다. 같은 슬롯의 해외 구단 교체는 이적으로 남긴다.
2. 이미 정한 진로와20주 답변이 충돌하던 문제를 약속 재확인 선택으로 바꿨다.
3. 손상된 선택 커리어 요약은 해당 요약만 무시하여 기존 결산과 선수 세이브가 계속 열린다.
4. 실제 계약을 통한 같은 구단 콜업도 승격으로 기록하고 이적 정착 지원을 차단한다.

실패 재현→수정→통과 검사를 추가했고 최종 독립 검토에서 위4건의 해결을 확인했다.

## 남은 경계와 다음 방향

실제 사용자 세이브 전체·모든 플레이 스타일·실제 Android/iOS·OS키보드·설치형PWA/APK 실행은 검증하지 않았다. 오프라인은 먼저 방문한 로컬 캐시의 재실행이다. 파이프라인 APK/ZIP은 기존 파일 존재·크기 검사이며 최신 코드 반영을 증명하지 않는다.

현재는 로컬 구현이며 커밋·push·배포·APK/ZIP 재빌드는 하지 않았다. 예고한3차는 이 커리어의 성과·인맥·자본을 계승하는 실제5인 로스터·FA·유망주/코치 운영이다. 자세한 방향은 `docs/CAREER_UPDATE_DESIGN_2026-11-04.md`, 장기 기획은 `docs/LONG_TERM_GAME_DESIGN.md`에 있다.

증거: `CAREER_UPDATE_VALIDATION_2026-11-04.json`, `CAREER_BALANCE_SIMULATION_2026-11-04.json`, 화면 `career-flow/`. 재현 코드는 `tests/career-flow.test.cjs`, `career-flow.browser.js`, `career-balance-simulation.cjs`, `result-motion.test.cjs`, `result-motion.browser.js`에 보존했다.
