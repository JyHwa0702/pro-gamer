# 밸런스 및 콘텐츠 결함 수정 실행 계획

목표: 검증 보고서에서 확인한 결함을 우선순위대로 수정하고 기존 세이브를 유지한다.
실행: 사용자가 보고서에 제시한 순서의 수정을 승인했으므로 현재 채팅에서 직접 구현한다. 기존 폴더 사용 및 미커밋 작업을 보존하고 별도 복사본/배포는 만들지 않는다.
기술: index.html 단일 Vanilla SPA, sw.js PWA, Node 내장 테스트와 Playwright.
명세: docs/reports/BALANCE_CONTENT_AUDIT_2026-11-03.md

## 제약
- 연령은 모든 참여자 19세 이상. 미성년 구간에는 건전한 응원과 공개 장소 대화만 제공.
- 기존 proRoadSave_v4/v3/v2/v1와 progamer_save를 읽고 알 수 없는 필드·획득 기록·자산을 보존.
- 신규 주간 상태는 null-safe 기본값과 연도+주 키 사용.
- 버전과 캐시는 동시에 올리되 커밋/push/배포는 하지 않음.

## 검토 초점
- 성인 커리어에서 미성년 커리어로 재시작/로드 시 데이터 잔류.
- 잔액 부족·중복 입력·취소·오래된 세이브에서 중복 정산과 자원 손실.
- 자동/수동 경기의 정산 동등성 및 결승 세트 포맷.
- 해금 조건 경계, 세 가지 드래프트 선택 및 회차 계승.
- 데이터만 있던 자산·DM 버튼의 저장/복귀와 하위 호환성.

## 순차 작업
1. Node vm 회귀 검사: 보고서의 재현 사례를 실패 검사로 고정.
2. 연령: 원본 데이트 복원, 공통 장면 보호, 두 참여자 19세와 호감도100 조건.
3. 주간: 검사 전 상태 변경 제거, 실제 주 종료에만 정산/횟수 초기화, 공통 데이트 실행·주1회·체력/돈 비용, SNS/DM/선물 보상 상한.
4. 콘텐츠: 신규10인 명시 조건 해금, 숫자 모달 선택/취소 계약 수정, 드래프트 선택/기존회차 연령, 자산/상점/SNS 연결.
5. 경기/성장: 공통 경기 정산, 유효 추천, OVR연동, 최대체력/특성/보너스 적용, 일정·티어·시간·결승 규칙 통일.
6. 서사: 선택 결과 기록과 관계 반응, 기존 멀티인연 구조 유지. 광범위 신규 FA 콘텐츠는 새로 만들지 않고 기존 회차 진입 복구.
7. 검증: 모든 Node 회귀검사, verify_pipeline.js, vm.Script, 버전 일치, 브라우저 주요흐름/기존세이브 로드, git diff 검사.
8. HANDOFF/체크리스트/결과 보고서에 통과 항목과 실제기기/APK 등 미검증 범위 기록.

## 실행 완료 기록

1~8단계 로컬 구현·검증 및 인계 기록 완료. 결과 보고서: `docs/reports/BALANCE_FIX_RESULTS_2026-11-03.md`. 독립 리뷰에서 확인한 댓글 보상 우회·계약 취소·JSON DM·월즈 결승 라벨 및 보상 표시/스토리 갱신 누락을 추가 회귀로 고정했다. 배포·APK는 별도 단계로 남겼다.
