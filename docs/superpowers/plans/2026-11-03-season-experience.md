# 한 시즌 경험 통합 업데이트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 사용자는 기획 문서화와1차 묶음 구현·검증까지 승인했다. 기존 작업 폴더와 미커밋 변경을 유지한다.

**Goal:** 목표→경기/라이벌→인연 반응→돈·인기 활용→26주 결산이 이어지는 한 시즌을 완성한다.

**Architecture:** 단일 `index.html`의 기존 주간/경기 결과를 관찰하는 시즌 상태와 서사·활동·읽기 전용 기록 UI를 추가한다. 기존 보상/경기 수식을 유지하고 신규 활동만 명시적으로 제한 정산한다.

**Tech Stack:** Vanilla HTML/CSS/JS, Node VM, Playwright CLI.

**Spec:** `docs/LONG_TERM_GAME_DESIGN.md`.

## Global Constraints

- 세이브 키·기존 상태·연령 보호·주간 데이트/SNS 제한·단일 파일/PWA 유지.
- 선택 필드는 null-safe. 중간 합류·새 커리어·연차·자연 은퇴 구분.
- 목표는 기록/서사 보상. 활동 각 종류 시즌1회, 비용·팬/OVR/체력 조건 확인, 취소·닫기·재열람 무소모.
- 신규 에셋 없음. 기존 초상화 fallback 유지. UI 문자열 escape.
- v2.5.0/17 동기화. 커밋·push·배포·APK 재빌드 없음.

## Review Focus

- 시즌 중간 구세이브에서 이전 주를 소급 실패하거나 자산을 초기화하지 않는다.
- 모달 닫기·동시 진행·재로드로 활동 중복/주차 중복/이야기 교착이 발생하지 않는다.
- 시즌 결산을 주차26에서 한 번 저장하고 자연 은퇴/새 회차에 섞지 않는다.
- 목표/라이벌/대회 표시가 실제 경기·리그 탈락·이적에 맞는다.
- 신규 활동 미사용 경로는 기존 정산·난수와 같다. 참여 경로는 명시된 유한 효과만 생긴다.
