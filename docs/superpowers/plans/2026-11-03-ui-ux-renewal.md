# 전체 UI UX 개선 실행 계획

2026-11-03. 사용자가 전체 개선 판단을 위임한 범위에서 기존 단일 파일 앱을 개선한다.

- 공통: 차분한 다크 팔레트, 간격/모서리/버튼/포커스 체계 통일. 아이콘은 로컬 인라인SVG, 기존 초상화/챔피언 이미지 사용. 새 외부 의존성 없음.
- 홈: 중복 추천/상태 안내 제거, 이번주 추천과 행동별 자원 변화를 우선 표시. 능력치/성장 로드맵은 펼침 패널. 인연은 해금된 주요 초상화로 요약.
- 내비게이션: 본문과 분리한 고정 하단6개 메뉴, 배지·한글 이름·접근성 레이블 유지. 기록/은퇴 화면으로 가는 경로 제공.
- 모달/인연/상점: 동일 스타일·터치 영역, 초상화 카드, 조건/패시브 상세 접기, 실제 행동 연결. 서사와 비용/조건/결과 문구는 보존.
- 생성 화면: 단계와 선택 상태 명확화, 선택한 특성의 설명만 강조, 다운로드/보조 안내는 접기.
- 검증: 기존65검사+UI회귀, 표준파이프라인/구문/버전동기화,320/390/1100px 브라우저 흐름과 스크린샷. 기존 세이브/연령/주간보상 규칙 유지.
- 결과/다음기획: UI 변경과 확인 범위를 기록하고 이후에는 시즌 요약→관계 기억→구단주 로스터 순서의 기획을 제안한다. 배포/새 에셋/게임 규칙 확장은 별도.

완료: 로컬 v2.3.0/15 적용,70개 회귀 및 브라우저 UI/기존흐름 통과. 상세 결과와 차기 제안은 `docs/reports/UI_UX_RENEWAL_AND_NEXT_PLAN_2026-11-03.md`에 기록. 배포/APK는 미실시.
